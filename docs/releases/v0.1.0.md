Solar Management lets visitors explore simulated solar installations and registered users manage their own sites. This first version rebuilds the monitoring flow around explicit units, ownership checks, and explainable calculations.

## Included

- Registration, login/logout, password hashing, PostgreSQL sessions, CSRF protection, and authentication rate limits.
- User-owned installation creation, editing, and deletion, with ownership enforced in parameterized SQL.
- Reading ingestion, latest readings, UTC history filters, responsive charts, and a local authenticated HTTP simulator.
- Trapezoidal energy estimates that retain zero readings, skip gaps over 30 minutes, avoid extrapolation, and report coverage.
- Transactional reading/alert creation, retry-safe ingestion, at most one unresolved alert per type/site, and alert resolution.
- Three read-only demo installations with a reproducible September 11–18, 2026 dataset. All readings are explicitly simulated.
- Docker Compose startup/migrations, persistent PostgreSQL storage, backup/restore tooling, and portfolio subpath hosting.

## Limits

This is a portfolio demonstration with simulated data and fixed temperature/voltage rules, not a hardware monitoring or equipment-control system. Forecasts, PDF reports, battery monitoring, email verification, password reset, and account deletion are not implemented. Authentication rate limits currently assume one application instance. Energy coverage describes observed time intervals, not sensor accuracy.

The repository documents its AI-assisted rebuild. Independent learning review remains separate from software verification and is tracked privately in `questions.md`.
